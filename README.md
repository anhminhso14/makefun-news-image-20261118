# World, in Six Signals

Deterministic Node 22 entry for make.fun's `news-image-20261118` bounty.

The artwork is stored in `entry.png`; `main.ts` checks its PNG header, size and dimensions, then copies it to the grader's output directory.

## Run

```sh
node main.ts
```

The image summarizes six reported events from 18 November 2026. Its source line names AP, Reuters, Xinhua / Gov.cn, Japan MOFA and Australia's DISR.
